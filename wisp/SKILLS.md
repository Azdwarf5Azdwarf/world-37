# Skills

Vad som redan finns och rakar hit.

| Skill | Nar den galler har |
|---|---|
| `tavla` | rita upp remsans arkitektur istallet for en chattvagg |
| `tmux-tentacles` | starta och hitta tillbaka till wisp-sessionen |
| `update-config` | andra `~/.claude/settings.json` och hookarna |
| `thread` | `\|thread` nar traden borjar tappa mal |
| `eot` | avsluta ett pass har inne |

## Egen skill senare

En `wisp`-skill vore rimlig nar remsan har fler an en kalla:
starta servern, visa senaste ordet, tolka en fargsekvens i ord.
Inte an — den skulle bara vara ett omslag runt `serve.py`.

## Regler

- Skills ar manuella triggers. Ingen auto-hook som startar dem.
- Anropa skillen fore arbetet, inte efter.
