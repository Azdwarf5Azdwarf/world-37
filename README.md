## Wiki

Wikin ligger i [`docs/`](docs/) och byggs med [Mintlify](https://mintlify.com).
Borja i `docs/index.mdx`.

Se den lokalt (kor i en egen terminalflik, den stangs om terminalen stangs):

```sh
cd docs
npx mint@latest dev
```

Oppnas pa <http://localhost:3000>. Stang med Ctrl+C.

Kontrollera lankar innan du pushar:

```sh
cd docs
npx mint@latest broken-links
```

<sub>Den globalt installerade `mint` 4.2.819 skriver "preview ready" men startar ingen server. Anvand `npx mint@latest`.</sub>
